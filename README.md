# SneakLock

Fabric 1.21.11 client-side mod. Press sneak once and you keep crouching, even
after releasing Shift and even while typing or in menus. Press **J** (with no
screen open) to stop. Rebind it in Controls > Misc.

All files are in the repo root (flat layout) except `.github/workflows/build.yml`.

## Get the jar
Go to the **Actions** tab > latest "Build mod jar" run > download the
`sneaklock-jar` artifact (contains `sneaklock-1.21.11-fabric.jar`). Put the jar in `.minecraft/mods` with Fabric API.
